🔑 Admin API Access Token তৈরির নিয়ম

নিচের ডিরেক্ট লিংকে ক্লিক করলে সরাসরি আপনার স্টোরের অ্যাপ তৈরির পেজ ওপেন হবে:

🔗 Open App Development in Shopify
  1. ১. অ্যাপ তৈরি করুন উপরের লিংকে গিয়ে "Create an app" বাটনে চাপ দিন এবং নাম দিন Catalog Importer।
  2. ২. স্কোপ কনফিগার (জরুরি) Configuration ট্যাবে যান ➔ Admin API integration-এর পাশে Configure চাপুন ➔ write_products, read_products, write_files, read_files টিক দিয়ে Save দিন।
  3. ৩. Install App দিন API credentials ট্যাবে গিয়ে Install app বাটনে ক্লিক করুন।
  4. ৪. Reveal Token Once! একদম উপরে Admin API access token সেকশনে "Reveal token once" বাটনে চাপ দিলেই shpat_... টোকেন পাবেন। এটি কপি করুন!

⚠️ কেন আপনি শুধু Client ID এবং Client Secret দেখতে পাচ্ছেন?

  • স্কোপ Save করা হয়নি: যদি ২ নম্বর ধাপে Configuration-এ গিয়ে স্কোপ Save না করে সরাসরি Install দেন, তবে Admin Access Token জেনারেট হয় না। সেক্ষেত্রে Configuration-এ গিয়ে পারমিশন Save করে আবার API credentials-এ আসুন।
  • Reveal Token Once মিস করেছেন: পেজের উপরে "Admin API access token"-এর পাশে থাকা "Reveal token once" বাটনে চাপ দিন। নিচের Client ID & Secret সেকশন দেখে বিভ্রান্ত হবেন না।
  • অথবা Client Credentials ব্যবহার করুন: আপনি চাইলে সরাসরি নিচের "Use Client ID & Secret" বাটনে চাপ দিয়ে আপনার Client ID ও Client Secret ইনপুট দিয়ে কানেক্ট করতে পারেন!
